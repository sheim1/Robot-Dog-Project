Robot Dog Project

Project Description

This project is a 3D design of a robot dog created using Fusion 360. The project focuses on designing the main body and parts of a robot dog as a 3D model.

Project Objective

The main objective of this project is to create a 3D model of a robot dog and develop skills in 3D modeling and computer-aided design (CAD).

Software Used

Autodesk Fusion 360

Project Components

The robot dog design consists of several main parts, including:

Robot dog body
Legs
Head
Other supporting parts

Project Files

This repository contains the project files and documentation related to the robot dog design.

Conclusion

This project helped me improve my skills in 3D modeling and learn more about designing mechanical parts using Fusion 360.
